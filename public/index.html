⚠️ Configuração necessária — tabela bot_settings não existe no Supabase
Execute o SQL abaixo no Supabase Dashboard → SQL Editor, depois clique em Salvar novamente: 
CREATE TABLE IF NOT EXISTS bot_settings (
  store_id        uuid PRIMARY KEY REFERENCES stores(id),
  nome_loja       text,
  whatsapp        text,
  saudacao        text,
  horario_inicio  text DEFAULT '09:00',
  horario_fim     text DEFAULT '18:00',
  bot_ativo       boolean DEFAULT true,
  ignorar_horario boolean DEFAULT false,
  fallback_humano boolean DEFAULT true,
  delay_resposta  boolean DEFAULT true,
  updated_at      timestamptz DEFAULT now()
);

Horário de atendimento

Define quando o bot responde automaticamente. Fora desse horário, o bot envia mensagem de encerramento.

Horário ativo: seg–sáb das às · Modo 24/7 ativo

Comportamento do bot

Bot ativo

Responder mensagens automaticamente. Desativando, o bot ignora todas as mensagens recebidas.

Ignorar horário 24/7

Responder mesmo fora do horário configurado. Útil para testes e campanhas.

Fallback para humano

Acionar atendente quando o bot não conseguir resolver a situação do cliente.

Delay de resposta

Simular ~800ms de "digitando..." antes de cada resposta do bot (mais natural).
